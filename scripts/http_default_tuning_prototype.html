Guided walkthroughs

Start with a server that accepts every request. Watch the target stay at its ceiling and no capacity feedback appear.

The origin accepts four connections. Compare a fixed target with the recommended backoff: the fixed target keeps asking for more than the server allows.

The origin accepts two HTTP/2 sessions with eight streams each. Four configured streams leave half of that capacity unused and trigger refusals.
